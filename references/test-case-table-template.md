# 测试用例表模板

适用于需要输出标准测试用例表的场景。默认字段如下：

| 字段 | 说明 |
|---|---|
| 用例ID | 唯一标识，建议按模块分组编号，如 `TC-MUI-001` |
| 模块 | 功能模块名称 |
| 用例标题 | 用一句话描述测试目标 |
| 前置条件 | 执行前必须满足的状态、环境、版本、数据条件 |
| 操作步骤 | 必须与预期结果一一对应，统一使用 `#` 编号 |
| 预期结果 | 必须与操作步骤一一对应，统一使用 `#` 编号；无内容也保留空 `#` |
| 优先级 | 如 `P0 / P1 / P2` |
| 备注 | 补充说明、临时假设、依赖限制、是否待确认 |

## 标准格式要求

### 操作步骤
- # xxx
- # xxx
- # xxx

### 预期结果
- # xxx
- # xxx
- # xxx

## 注意事项
1. 操作步骤和预期结果必须逐项对应。
2. 不要把多个独立预期堆成一整段。
3. 如果某一步没有明确预期，也必须保留空的 `#`。
4. 前置条件要写清楚版本、状态、数据、网络、时间窗口等关键条件。
5. 复杂项目建议先有测试点和覆盖矩阵，再正式填表。
